# 작업 방식

## 단편영화
총 한 달의 작업 기간. 2주는 편집실에서 소스 정리부터 가편집본을 뽑아내는 데에 시간을 할애하고, 2주 후 감독님께 편집본을 전달. 이후 2주 동안 감독님과 스케줄 협의 후 함께 세 번의 파이널을 진행.

## 독립장편예술영화 / 상업영화
프리 단계부터 지속적인 시나리오 피드백, (감독님께서 원하실 경우) 콘티 단계에 참여. 작품 촬영과 동시에 데이터가 업로드된 후 일주일 내로 순서편집본을 전달. 이후 순서편집본을 추합해 전체적인 흐름과 구조를 잡고 가편집을 진행해 전달. 구성 변경이 필요한 경우 시나리오 버전과 구성 변경 버전 두 버전을 전달. 추후 감독님과 함께 파이널을 진행하며 디벨롭, 제작사 의견을 추합하여 작품을 완성.

## (OTT 포함) 드라마
프리 단계부터 지속적인 시나리오 피드백, (감독님께서 원하실 경우) 콘티 단계에 참여. 작품 촬영과 동시에 데이터가 업로드된 후 2일 내로 순서편집본을 전달. 에피소드별로 흐름과 구조를 잡고 가편집을 진행해 전달. 구성 변경이 필요한 경우 시나리오 버전과 구성 변경 버전 두 버전을 전달. 추후 감독님과 함께 파이널을 진행하며 디벨롭, 제작사 의견을 추합하여 작품을 완성.
